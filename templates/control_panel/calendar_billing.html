Calendar-month billing

Usage runs from the 1st to the last day of each month. Statements close only after verified meters finish. Wallet collection starts on the configured Payment Start Day of the following month. Payment End Day is the last grace day; overdue restriction starts the day after.

Credit Wallet

Billing policy and Celery timing

Usage closes at calendar month-end. Set the rate duration separately from the calculation intervals. File changes update the stored byte total immediately; the storage interval accrues elapsed time without re-reading every file. Active staff login accounts are billable; customer records are excluded. Feature OFF stops new accrual.

New companies may accrue verified postpaid usage with zero wallet credits during the grace period when enabled. No negative balances or partial charges are created. Prior months are not charged retroactively when this policy is first enabled.
