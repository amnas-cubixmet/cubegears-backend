Storage Credits — separate billing policy

Charge credits based on real company MediaFile bytes. Disabled by default. One ledger charge per day/month when a backend scheduler runs; no card payment occurs here.

{% csrf_token %}

Run python manage.py bill_storage_credits --dry-run to preview. Then schedule python manage.py bill_storage_credits once daily on one instance. Storage charges are wallet credits, not INR.
